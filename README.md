# Tea Landing Page

A responsive tea shop landing page built with Bootstrap as part of my frontend development training.

The project demonstrates the use of Bootstrap components and responsive layout techniques to create a structured website that adapts to different screen sizes.

## Technologies

- HTML5
- CSS3
- Bootstrap
- JavaScript

## Features

- Responsive layout
- Mobile navigation
- Product cards
- FAQ accordion
- Order form
- Bootstrap components
- Mobile-friendly interface
